"# JSON Diff & Merge Tool\n\n一个功能强大的 JSON 文件对比和合并工具，支持多文件对比、Git 风格差异展示、可视化选择和导出。\n\n## ✨ 功能特性\n\n- 📁 **多文件上传**：支持同时上传 3 个或更多 JSON 文件\n- 🔍 **结构化 Diff**：自动分析所有文件的结构差异\n- 🎨 **Git 风格展示**：使用颜色标记新增、删除、修改和未变更的字段\n- 🌳 **树形视图**：可展开/折叠的层级结构，清晰显示嵌套关系\n- ✅ **候选值选择**：每个字段显示所有文件的候选值，点击选择要合并的数据\n- 👁️ **实时预览**：右侧实时显示合并后的 JSON 结果\n- 📥 **一键导出**：将合并结果导出为 JSON 文件\n- 🚀 **纯前端**：无需后端服务器，双击 index.html 即可运行\n\n## 🚀 快速开始\n\n### 方法 1：直接运行\n\n1. 双击 `index.html` 文件\n2. 在浏览器中打开\n3. 开始使用！\n\n### 方法 2：使用本地服务器\n\n```bash\n# 使用 Python\npython3 -m http.server 8000\n\n# 或使用 Node.js\nnpx serve\n```\n\n然后在浏览器中访问 `http://localhost:8000`\n\n## 📖 使用指南\n\n### 步骤 1：上传文件\n\n- 点击"选择文件"按钮，或直接拖拽 JSON 文件到上传区域\n- 支持同时上传多个文件（建议 3 个以上）\n- 上传的文件会显示在下方列表中\n\n### 步骤 2：开始对比\n\n- 点击"开始对比"按钮\n- 系统会自动分析所有文件的差异\n- 显示统计信息：新增、删除、修改、未变更的字段数量\n\n### 步骤 3：选择合并值\n\n- 左侧显示差异树，每个字段标记了状态（新增/删除/修改/未变）\n- 点击每个字段下的候选值来选择要合并的数据\n- 右侧会实时更新合并后的 JSON 预览\n\n### 步骤 4：导出结果\n\n- 点击"导出合并结果"按钮\n- 自动下载合并后的 JSON 文件\n- 文件名包含时间戳，例如：`merged-2024-01-15T12-30-45.json`\n\n## 🎨 颜色说明\n\n- 🟢 **绿色**：新增的字段\n- 🔴 **红色**：删除的字段\n- 🟡 **黄色**：修改的字段（不同文件中值不同）\n- ⚪ **灰色**：未变更的字段（所有文件中值相同）\n\n## 📁 项目结构\n\n```\nJSON_diff/\n├── index.html      # 主页面\n├── style.css       # 样式文件\n├── diff.js         # Diff 计算引擎\n├── merge.js        # 合并逻辑引擎\n├── main.js         # 主控制器\n└── README.md       # 说明文档\n```\n\n## 🔧 技术栈\n\n- **纯原生 JavaScript (ES6+)**：无任何外部依赖\n- **原生 CSS3**：使用 Flexbox 和 Grid 布局\n- **模块化设计**：清晰的职责分离\n\n## 💡 示例场景\n\n### 场景 1：配置文件合并\n\n假设你有三个环境的配置文件：\n- `config-dev.json`\n- `config-staging.json`\n- `config-prod.json`\n\n使用本工具可以：\n1. 查看三个文件的所有差异\n2. 为每个字段选择最合适的值\n3. 生成统一的配置文件\n\n### 场景 2：数据迁移\n\n从不同数据源导出的 JSON 数据需要合并时：\n1. 上传所有数据文件\n2. 识别字段差异和冲突\n3. 手动选择保留哪些数据\n4. 导出清洗后的数据\n\n### 场景 3：API 响应对比\n\n对比不同版本 API 的响应结构：\n1. 上传各版本的 API 响应\n2. 查看结构变化\n3. 选择兼容的字段组合\n4. 生成统一的数据模型\n\n## 🌟 特色功能\n\n### 1. 深度递归对比\n\n- 支持任意深度的嵌套对象\n- 支持数组元素的逐个对比\n- 正确处理 `null`、`undefined`、空值\n\n### 2. 智能默认选择\n\n- 自动选择第一个存在的值作为默认\n- 减少手动操作次数\n\n### 3. 实时预览\n\n- 每次选择立即更新预览\n- 确保最终结果符合预期\n\n### 4. 展开/折叠\n\n- 大型 JSON 文件可折叠节点\n- 聚焦关注的部分\n\n## 🐛 已知限制\n\n1. **大文件性能**：超过 10MB 的 JSON 文件可能导致浏览器卡顿\n2. **数组对比**：数组元素按索引对比，不支持智能匹配\n3. **循环引用**：不支持包含循环引用的 JSON\n\n## 📝 更新日志\n\n### v1.0.0 (2024-01-15)\n\n- ✅ 初始版本发布\n- ✅ 支持多文件上传\n- ✅ 结构化 Diff 引擎\n- ✅ Git 风格可视化\n- ✅ 候选值选择\n- ✅ 实时合并预览\n- ✅ JSON 导出功能\n\n## 🤝 贡献\n\n欢迎提交 Issue 和 Pull Request！\n\n## 📄 许可证\n\nMIT License\n\n---\n\n**享受使用吧！** 🎉"
